# 狗狗自主动作方案 · 系统通知只弹一次的问题分析（待审定）

> 第一部分：系统通知问题的分析，暂不修改，只给出判断方法与修复选项。
> 第二部分：狗狗自主动作的设计（10 个随机动作 + 2 个联动动作，默认活跃程度「正常」），审定后开工。

## 一、系统通知只弹了一次

### 1.1 现象

- 开启喝水提醒（含「同时弹系统通知」）后，右下角弹出过**一次**来源为「Windows PowerShell」的通知。
- 关掉这条通知后打开通知中心，**里面是空的**。
- 之后再也没有弹出系统通知；便签里的狗狗提醒是否每次都出现，待确认（见 1.4 第 3 条）。

### 1.2 现在的实现

- 绿色版默认不写注册表，所以系统通知借用 Windows 自带 PowerShell 的通知身份发出，来源显示为「Windows PowerShell」。这是设计如此，启用「系统集成」后才显示为「桌面备忘钉」。
- 每发一条通知，程序都会**新开一个隐藏的 PowerShell 进程**，执行一段编码后的脚本（`powershell -EncodedCommand …`）来调用 Windows 的通知接口。
- 喝水 / 起身提醒的所有通知都使用**同一个标签**（`pet`），没有设置过期时间。
- 发送失败时，日志里会写「发送通知失败：…」；**发送成功不记日志**，所以目前从日志无法确认后来的通知到底发没发。
- 便签里的狗狗每次弹出提醒时，前端都会请求后台发一次系统通知。

### 1.3 可能的原因（按可能性排序）

| # | 推测 | 能解释的现象 | 不能解释的 |
|---|---|---|---|
| A | **安全软件拦截了后来的 PowerShell**。「隐藏窗口 + 编码命令」的 PowerShell 正是恶意软件常用的写法，公司电脑上的杀毒 / 终端防护（EDR）常常第一次放行、随后按行为特征拦截 | 第一次能弹、之后都没有；通知中心里也没有（根本没发出去） | — |
| B | **Windows 对「Windows PowerShell」这个来源的通知设置**：横幅开着、但「在通知中心显示」被关闭，或系统把它归为不重要的来源 | 关掉横幅后通知中心是空的 | 后面为什么连横幅都没有 |
| C | **同一标签互相替换**：新通知带着同一个标签，会替换掉旧的那条；某些情况下替换只更新、不再弹横幅 | 后面不再弹横幅 | 你关掉第一条后通知中心已空，按理不存在「被替换」的旧通知，所以可能性不大 |
| D | **专注助手 / 勿扰模式**（定时、全屏、演示时自动开启）把横幅压住了 | 后面不弹横幅 | 被压住的通知通常仍会进通知中心 |
| E | **后面的提醒根本没触发**：比如那时离开电脑超过 5 分钟、已过下班时间，或便签里的提醒也没再出现 | 一切 | 需要你确认便签里的狗狗是否每次都提醒了 |

我目前的判断：**A 最可能**，B 可能同时存在。C、D 解释不了「通知中心为空」。

### 1.4 请你帮忙确认（不需要改程序）

1. 打开 `logs\app.log`（绿色版在 `data\logs\`），搜「发送通知失败」。**有**：原因多半是 A，把那几行发给我。**没有**：再看下面几条。
2. 打开 Windows 设置 → 系统 → 通知，在应用列表里找「Windows PowerShell」，看「通知」「横幅」「在通知中心显示」三个开关的状态。
3. 后来几次到点时，便签里的狗狗**有没有**弹出「喝口水吧 / 起来走走」的提醒？
4. 这台电脑是否装了杀毒 / 终端防护软件、是否为公司管理的电脑？有没有出现过拦截提示？
5. 当时有没有开着专注助手 / 勿扰模式，或者正在全屏放映？

### 1.5 修复选项（等你确认原因后再定，现在不动）

| 选项 | 做法 | 解决 | 代价 |
|---|---|---|---|
| ① 小修 | 每条通知用不同的标签；30 分钟后自动从通知中心消失；**每次发送都记日志**（成功 / 失败 / 耗时） | C；方便以后排查 | 解决不了 A、B |
| ② 测试按钮 | 设置 → 摸鱼里加「发送一条测试通知」，可随时复现 | 方便定位 | 无 |
| ③ 改用原生接口（根治 A） | 不再启动 PowerShell，由程序直接调用 Windows 的通知接口。项目依赖里已经有现成的 Go 实现（go-toast，Wails 自带依赖），无需额外下载 | A；每次发通知也不再新开进程 | 改动较大，需在 Windows 实机验证；它默认会向注册表登记通知身份，要确认在「绿色版零写入」模式下能否关掉 |

建议：先做 ① + ②（改动小、有了日志和测试按钮才好定位），确认是 A 后再做 ③。

## 二、狗狗的自主动作

### 2.1 原则

- 狗狗**醒着、心情平常、没有在做别的事**时，隔一段时间随机做一个小动作；同一个动作不会连着做两次。
- 动作幅度小、时长短（1–8 秒），不遮挡事项，不发出声音。
- **以下情况不做**：正经模式；狗狗正在提醒 / 说话 / 被拖动 / 玩球 / 做互动动作；睡觉或打盹；右键菜单或对话框开着；便签被隐藏或最小化。
- 你点它、拖它时，正在进行的自主动作**立即打断**，按你的操作来。

### 2.2 活跃程度（设置 → 摸鱼 → 狗狗）

| 档位 | 间隔 | 说明 |
|---|---|---|
| 安静 | — | 不做随机动作（联动动作仍然有） |
| **正常（默认）** | 每 1–3 分钟一次 | |
| 活泼 | 每 30–90 秒一次 | |

### 2.3 十个随机动作

| # | 动作 | 表现 | 时长 | 备注 |
|---|---|---|---|---|
| 1 | 打哈欠 | 嘴张大、眼睛眯起、身体微微拉长 | 1.5 秒 | |
| 2 | 挠痒痒 | 一只后腿抬起来挠耳朵，头歪向一边 | 2 秒 | |
| 3 | 抖抖身子 | 全身快速左右抖几下，耳朵甩动，身边飞出几道小线条 | 1 秒 | |
| 4 | 东张西望 | 眼睛先看左、再看右，头跟着歪 | 3 秒 | |
| 5 | 追尾巴 | 原地转一圈，停下后头顶冒两颗晕乎乎的小星星 | 2.5 秒 | |
| 6 | 擦眼镜 | 摘下眼镜（露出没戴眼镜的小眼睛），哈一口气、用爪子擦一擦，再戴回去 | 3 秒 | 戴眼镜狗的专属动作 |
| 7 | 看书 | 拿出一本小书低头看，中间翻一页；偶尔冒一句「博士在学习」 | 6 秒 | 墨镜款时改成「看杂志」 |
| 8 | 巡逻 | 沿着便签底部慢慢走到另一头，再走回来 | 6 秒 | 便签太窄（小于 240 像素）时不做；走动时不挡列表点击 |
| 9 | 捉蝴蝶 | 一只小蝴蝶从上方飘过，狗狗跳起来扑一下，蝴蝶飞走 | 3 秒 | 蝴蝶永远飞走，不「抓到」 |
| 10 | 趴下休息 | 趴下、下巴贴地、眼睛半闭，过一会儿坐起来 | 8 秒 | 与「打盹」不同：只是短暂趴一下 |

挑选方式：按权重随机，常见动作（东张西望、打哈欠、挠痒痒）出现得多些，大动作（巡逻、捉蝴蝶、看书）少些；不连续重复同一个。说话气泡仍受「每小时最多一次」的限制，动作本身不说话（看书偶尔例外，也计入这个限制）。

### 2.4 两个联动动作

| # | 动作 | 触发 | 表现 | 结束 |
|---|---|---|---|---|
| 11 | 看你打字 | 你在便签里的输入框（添加事项、编辑、搜索）打字 | 歪着头、眼睛盯向输入框的方向 | 停止打字 2 秒后恢复；睡觉 / 打盹时不理会 |
| 12 | 翻肚皮 | 鼠标在它身上停留超过 3 秒（不点击） | 躺倒、肚皮朝上、四只爪子举起来 | 鼠标移开或 6 秒后坐起来；这时点它算「挠肚皮」：冒双倍爱心，计一次摸头 |

联动动作不受活跃程度影响，「安静」档也会做；正经模式下不做。

### 2.5 技术要点

- **调度做成纯函数**：输入当前状态（心情、是否忙、活跃程度、上一个动作、随机数），输出「下一个动作 + 间隔」，便于单元测试。
- **画面全部用 SVG + CSS 动画**，同一时间只播一个动作；便签隐藏时浏览器自动暂停动画，计时器也暂停。
- 新增的画面元素：张嘴（哈欠）、抬后腿、晕乎乎的星星、摘下的眼镜和小眼睛、小书、蝴蝶、趴下和翻肚皮两个姿势。
- 不改数据库；只新增一个设置「活跃程度」（安静 / 正常 / 活泼，默认正常）。

### 2.6 测试

- **单元测试**：调度不连续重复、各档位间隔在范围内、「安静」不出随机动作；各种「不做」条件（正经模式、睡觉、忙碌、菜单打开）。
- **端到端测试**：用可控的页面时钟快进，确认「活泼」档会出现动作、「安静」档不会；悬停 3 秒翻肚皮、此时点击计为摸头；在添加框里打字时眼睛朝向输入框；点击能打断正在进行的动作。
- **需要你实机验收**：动作频率是否合适、会不会让人分心、动画是否流畅（CPU 占用）。

### 2.7 工作量

中等偏多，主要花在 8 个新姿势的绘制和动画调整上。完成后与（你决定要做的）通知修复一起发 v1.0.3。
