## 一、财经订阅源

在预置订阅源里新增「财经」分类，4 个源**默认都不勾选**。已经订阅过的用户不会被自动加上，需要时在 设置 → 摸鱼 →「预置订阅源…」里勾选添加。

| 名称 | 地址 | 依据 / 风险 |
|---|---|---|
| 长桥·金融快讯 | `https://longportapp.cn/news/live/feed` | 搜索引擎收录了这个 RSS 本身，把握较高 |
| FT中文网 | `https://www.ftchinese.com/rss/feed` | 常见公开地址；部分文章需付费，标题可看 |
| 中国新闻网·财经 | `https://www.chinanews.com.cn/rss/finance.xml` | 按中新网现有滚动源的地址规律推断 |
| 新浪财经·要闻 | `http://rss.sina.com.cn/roll/finance/hot_roll.xml` | 老接口，只有 http，可能已停更（GBK 编码已支持） |

- 这些地址在开发环境里都无法访问验证。预置列表里会在名称后标「（待验证）」，你在电脑上点「测试」后告诉我结果，打不开的下一版删掉，能用的去掉标记。
- 不做：大盘 / 个股行情（不是 RSS，需要行情接口和数据授权）；华尔街见闻、财联社、金十（没有官方 RSS，自建 RSSHub 的话可以直接粘贴地址）。

## 二、名字：默认「博士」，也可以自己起

- **默认名字改为「博士」。**
- **第一次开启狗狗时弹出起名框**：输入框里预填「博士」，下方有三个候选可以一键选（博士 / 摸摸 / 鱼丸），也可以自己输入（1–12 个字），点「就叫这个」完成。点关闭等于用默认名。
- 之后随时可以在狗狗右键菜单「改名…」或 设置 → 摸鱼 里修改。
- 台词里会用名字，例如「博士提醒你：喝口水吧」。
- **已经在养、名字还是旧默认「眼镜」的**：见文末问题 1。

## 三、新增互动

所有互动都在便签窗口内发生；鼠标穿透开启时狗狗不响应点击（与便签一致），正经模式下狗狗和所有互动一起收起。

| # | 互动 | 怎么触发 | 表现 | 细节 |
|---|---|---|---|---|
| 1 | 眼睛跟着鼠标 | 鼠标在便签上移动 | 眼珠朝鼠标方向偏移 | 睡觉 / 打盹 / 开心眯眼时不跟；鼠标离开便签后眼珠回正；按帧节流，不占 CPU |
| 2 | 双击握手 | 双击狗狗 | 抬起右爪 + 气泡「握手！」 | 为区分单击（摸头）和双击，单击会延迟约 0.25 秒生效 |
| 3 | 连点彩蛋 | 2 秒内连点 5 次 | 害羞脸红 → 打喷嚏 → 眼镜被震歪 3 秒 | 每分钟最多触发一次 |
| 4 | 叫醒 | 它在睡觉 / 打盹时点一下 | 揉眼睛，嘟囔「再睡五分钟…」 | 打盹被叫醒后 5 分钟内不再打盹；免打扰时段 10 秒后又睡着 |
| 5 | 时段问候 | 工作日到点时便签可见 | 上班时间后第一次出现「早！」；12:00 起「饭点到啦」；下班时间伸懒腰「下班啦！」（已有） | 每种每天最多一次；在浏览器本地记录当天说过没有 |
| 6 | 拖到另一边 | 按住狗狗拖动 | 跟手移动，松开后吸附到最近的左下 / 右下角并保存 | 移动超过 5 像素才算拖动，否则仍是单击 |
| 7 | 扔个球 | 右键「扔个球」 | 球从狗狗身边扔到便签另一侧，狗狗跑过去叼起来、跑回原位放下，约 4 秒 | 跑动时临时从角落移出、沿列表底部横穿（不挡点击）；统计「一起玩了 N 次」 |
| 8 | 节日装扮 | 按日期自动 | 元旦派对帽、春节红围巾、端午艾草（头顶小绿枝）、中秋兔耳、国庆红围巾、圣诞帽 | 节日当天前后共 3 天（春节为除夕至初七）临时替换配饰，过后恢复你选的；春节 / 端午 / 中秋按农历，内置 2026–2035 年的公历日期表并有单元测试；设置里可关闭 |
| 9 | 陪伴纪念日 | 第 7、30、100、365 天及之后每满一年 | 撒花 +「我们认识 100 天啦！」 | 当天第一次出现时触发一次 |
| 10 | 喝水 / 起身提醒 | 定时（**默认关闭**） | 狗狗叼来水碗（喝水）或伸懒腰（起身），气泡带两个按钮「好了」「10 分钟后」 | 间隔 30 / 45 / 60 / 90 分钟（默认 45），喝水和起身交替；只在工作日上班时间内提醒，免打扰时段、正经模式、你离开电脑（空闲超过 5 分钟）时不提醒；统计「今天喝了 N 杯」 |
| 11 | 看新闻推眼镜 | 新闻条换标题时 | 约三分之一的概率推一下眼镜 | 需要开启新闻 |

右键菜单调整后为：统计（新增「一起玩了 N 次」「今天喝了 N 杯」）→ 摸摸头 / 握个手 / 扔个球 / 喂零食 → 改名… / 换装 → 换到左下角 / 暂时收起。

**数据**：数据库升到 v6，宠物表新增「玩球次数」「当天喝水日期 + 杯数」；导出 / 导入一并包含。
**设置 → 摸鱼 → 狗狗** 新增：节日自动装扮（默认开）、喝水 / 起身提醒（默认关）+ 间隔。

## 四、下班倒计时：紧凑显示、金额悬停才显示、窄时分两行

**平时（紧凑）**

```
┌──────────────────────────────────────────┐
│ 下班 2:13 · ¥ ••   少数派：2026 年最值得买的… 3 │
└──────────────────────────────────────────┘
```

- 只显示时和分（每分钟更新，不再每秒跳动）：「上班 0:45」/「下班 2:13」/「已下班」/「周末」。
- 金额显示为「¥ ••」，不显示具体数字。

**鼠标悬停在倒计时上**：展开为「距下班 2:13:05 · 今天已赚 ¥386.20」，悬停期间每秒更新；移开后恢复紧凑。

**金额显示方式**（设置 → 摸鱼 → 下班倒计时）：悬停时显示（默认）/ 一直显示 / 不显示。没填月薪时不出现金额。

**宽度不够时自动分两行**：倒计时和新闻都开启、且便签宽度小于约 380 像素时，上一行倒计时、下一行新闻；拉宽后自动合回一行。只开一个时始终一行。

```
┌──────────────────────────────┐
│ 下班 2:13 · ¥ ••              │
│ 少数派：2026 年最值得买的机… 3 │
└──────────────────────────────┘
```

## 五、测试与工作量

- **单元测试**：农历节日日期表（与已知日期核对）、节日 / 纪念日判断、喝水提醒调度（工作时段、免打扰、空闲、正经模式）、单击 / 双击 / 连点 / 拖动的判定、紧凑倒计时文本、财经预置源格式。
- **端到端测试**：起名框、握手、连点彩蛋、拖到另一边、扔球（动画结束后计数 +1）、喝水提醒的「好了 / 10 分钟后」、倒计时悬停展开与金额隐藏、窄宽度自动分两行。
- **需要你实机验收**：4 个财经源能否访问；拖动和扔球在 Windows 上是否顺手（便签窗口里拖动不能和窗口拖动冲突）；喝水提醒的打扰程度。

| 阶段 | 内容 | 工作量 |
|---|---|---|
| 1 | 财经预置源 + 倒计时紧凑 / 金额 / 分两行 | 小 |
| 2 | 起名框 + 默认「博士」+ 互动 1–6、11 | 中 |
| 3 | 扔球、节日装扮、纪念日、喝水 / 起身提醒（数据库 v6） | 中 |

每个阶段单独提交并跑完整回归，全部完成后再发 v1.0.2。
