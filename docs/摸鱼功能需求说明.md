# 桌面备忘钉 · 摸鱼功能开发需求说明（草案 v0.1）

> 范围：**RSS 新闻订阅**、**桌面宠物「戴眼镜的狗狗」**，以及两者共用的「正经模式」（老板键）。
> 状态：待确认。文末「待你确认的问题」定下来后再开工。

---

## 0. 总原则

1. **全部可单独开关，默认关闭。** 不开启时界面、性能、网络行为与现在完全一样。
2. **一键收起。** 「正经模式」（老板键）一按，新闻条、宠物全部隐藏，再按恢复。
3. **网络只为 RSS 服务。** RSS 关闭时程序**零网络请求**（单元测试断言）；开启后只访问订阅列表里的地址，不上报任何数据，不带 Cookie。
4. **绿色版原则不变。** 新增数据都写进现有数据库 / `data` 目录，不写注册表、不写系统临时目录。
5. **不制造焦虑。** 宠物不会「死亡」、不会扣分；逾期只让它露出担心的表情。

## 一、RSS 新闻订阅（FR-701 ~ FR-709）

### 1.1 用户故事

- 我想在便签上瞄一眼最新标题，感兴趣再点开浏览器看，不想专门开网页。
- 我想自己挑订阅源，也能加自己常看的博客。
- 公司网络走代理时也要能用；网络不通时别弹一堆错误。

### 1.2 关于「实时」

RSS 是**定时拉取**，不是服务器推送。最短间隔 15 分钟（再短对方网站可能限流 / 封 IP）。界面和说明里如实写「每 N 分钟更新」，不写「实时」。

### 1.3 功能需求

| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-701 | 设置 → 摸鱼 → 「启用新闻订阅」，默认关闭。关闭时不发出任何网络请求 | P0 |
| FR-702 | **预置订阅源**（见 1.4）。首次开启时弹出勾选列表，默认勾选 3 个，用户可改 | P0 |
| FR-703 | **自定义订阅**：粘贴地址添加，自动识别 RSS 2.0 / Atom / RSS 1.0(RDF)；可重命名、停用、删除 | P0 |
| FR-704 | **定时拉取**：间隔 15 / 30 / 60 分钟（默认 30）；电脑唤醒后补拉一次；每个源独立，一个失败不影响其他 | P0 |
| FR-705 | **新闻条**：便签底部一行，轮播最新标题（每 8 秒换一条，鼠标悬停暂停），显示来源和「12 分钟前」；点击用默认浏览器打开原文 | P0 |

### 1.5 技术要点（实现时需要注意的坑）

- **系统代理**：Go 默认只认环境变量里的代理，**不认 Windows「设置 → 网络 → 代理」**。公司网络大多用后者，所以要读取 Windows 的当前用户代理设置（WinHTTP 接口）。设置里提供：跟随系统（默认）/ 不使用代理 / 手动填写。PAC 自动配置脚本放到 P2。
- **编码**：不少国内站点的 RSS 是 GBK / GB2312，不是 UTF-8，解析时按 XML 声明转码，否则标题乱码。
- **安全**：只允许 `http` / `https`；单个响应最多 2 MB；超时 10 秒；最多跟随 3 次重定向；只解析 XML，摘要里的 HTML 一律当纯文本显示（不执行脚本、不加载外部图片）；点击打开前再次校验链接是 http(s)。
- **礼貌拉取**：带 `If-None-Match` / `If-Modified-Since`（没更新时对方只回 304，几乎不耗流量）；失败按 1→2→4… 倍间隔退避，上限 4 小时；User-Agent 写明 `DeskPinMemo/版本`。
- **存储**：新表 `feeds`（订阅源）、`feed_items`（条目：标题、链接、摘要前 200 字、发布时间、已读）。每个源最多保留 100 条、7 天前的自动清理。数据库结构升到 v5。
- **版权**：只显示标题和摘要片段，点击跳原文，不抓取、不缓存全文。
- **备份 / 导出**：包含订阅列表，不包含条目（条目随时可以重新拉）。

## 二、桌面宠物：戴眼镜的狗狗（FR-801 ~ FR-810）

### 2.1 形象初稿

![戴眼镜的狗狗 · 初稿](images/pet-dog-draft.png)

左：放大预览；右：在深色主题便签里的实际大小（约 64×64）。

- 垂耳小狗，橘黄 + 奶白配色，柴犬式「麻吕眉」，黑框圆眼镜（镜片带反光），吐舌头。
- **纯矢量（SVG）手绘**，没有使用任何外部图片素材，不存在版权问题；放大缩小都清晰，深浅主题都能看清。
- 源文件：`docs/images/pet-dog-draft.svg`。形象定稿后再做各个表情和动作。

### 2.2 放在哪里

- 坐在便签**右下角**（可在设置里换到左下角），约 64×64，不挡事项文字；列表滚动时它不动。
- 便签折叠时只露出脑袋趴在标题栏边上。
- **限制**：只能待在便签窗口里，不能在整个桌面上跑来跑去（Wails v2 只支持一个窗口；想让它满屏跑需要单独的透明窗口，留待以后升级 Wails v3 再评估）。

### 2.3 功能需求

| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-801 | 设置 → 摸鱼 → 「养一只狗狗」，默认关闭；首次开启时给它起名（默认「眼镜」） | P0 |
| FR-802 | **表情 / 动作**（见 2.4），由状态自动切换，CSS 动画实现 | P0 |
| FR-803 | **互动**：单击摸头（摇尾巴 + 冒爱心）；右键菜单：喂零食、改名、换位置、暂时收起 | P0 |
| FR-804 | **和事项联动**：完成一个事项 → 狗狗叼走一根骨头，经验 +10；当天完成全部「今天」的事项 → 撒花庆祝 | P0 |
| FR-805 | **心情**：有逾期事项时露出担心的表情（不扣分、不惩罚）；处理完逾期立刻恢复 | P0 |
| FR-806 | **说话气泡**：偶尔冒一句（默认每小时最多 1 次，可关）。情境台词优先：「『交周报』已经逾期啦」「下班啦！」「新闻条有新鲜事」；否则随机摸鱼台词：「再摸 5 分钟就干活」 | P1 |
| FR-807 | **成长**：经验升级（1–10 级），升级解锁配饰（领结、围巾、帽子）和眼镜款式（圆框、方框、墨镜），可在右键菜单里换装 | P1 |
| FR-808 | **作息**：长时间没动鼠标 → 打盹；免打扰时段 → 睡觉（Zzz）；到设定的下班时间 → 伸懒腰 | P1 |
| FR-809 | **看新闻**：新闻条换标题时偶尔推一下眼镜（需开启 RSS） | P2 |
| FR-810 | 统计卡片：陪伴天数、帮你完成的事项数、当前等级 | P2 |

### 2.4 状态（优先级从高到低）

| 状态 | 触发 | 表现 |
|---|---|---|
| 庆祝 | 刚升级 / 今天的事项全部完成 | 跳起 + 撒花，3 秒 |
| 开心 | 刚完成事项 / 刚被摸头 | 摇尾巴、眯眼 |
| 担心 | 存在逾期事项 | 耷拉耳朵、眼镜滑到鼻尖 |
| 睡觉 | 免打扰时段 | 闭眼趴下、Zzz |
| 打盹 | 30 分钟无操作 | 点头打瞌睡 |
| 平常 | 其他 | 偶尔眨眼、歪头、推眼镜 |

规则做成纯函数（输入：逾期数、今日完成情况、空闲时长、免打扰、最近事件；输出：状态），配单元测试，和透明度规则的做法一样。

### 2.5 和现有功能的关系

- **鼠标穿透**开启时，宠物也不响应点击（与便签一致），但仍照常显示和做动作。
- **自动变淡 / 透明度**：宠物跟着便签一起变。
- **正经模式**：一键隐藏。
- **性能**：窗口隐藏、最小化或穿透期间暂停动画；动画全用 CSS，CPU 占用目标 < 1%。
- **数据**：新表 `pet`（名字、等级、经验、配饰、位置、创建时间），本地保存，参与备份 / 导出。

## 三、正经模式（老板键）

- 全局快捷键（默认 `Ctrl+Alt+H`，可改，冲突检测沿用现有逻辑）+ 托盘菜单项。
- 开启后：隐藏新闻条和宠物；可选「同时切到指定分组」（比如「工作」）。再按一次全部恢复。
- 与现有 `Ctrl+Alt+M`（隐藏全部便签）并存：一个是「全藏」，一个是「变正经」。

## 四、设置页

新增「摸鱼」标签页，内容依次是：

1. **新闻订阅**：开关、更新间隔、代理方式、订阅源列表（状态 / 测试 / 停用 / 删除 / 添加）、新条目通知开关
2. **狗狗**：开关、名字、位置、说话气泡开关、重置成长进度
3. **正经模式**：快捷键、切换到的分组

## 五、测试与验收

- **Go 单元测试**
  - RSS 解析：RSS 2.0 / Atom / RDF / GBK 编码 / 缺字段 / 非法 XML / 超过 2 MB / 重定向次数超限 / 非 http(s) 链接
  - 拉取：304 不更新、失败退避、唤醒补拉、关闭开关时零请求（用假的 HTTP 客户端计数）
  - 宠物：状态决策纯函数表驱动测试；经验 / 升级计算
- **端到端测试（Playwright）**：开发服务器内置一个假的 RSS 服务，测新闻条轮播、点击、列表、错误显示；宠物摸头、完成事项后的经验变化、正经模式一键隐藏
- **需要你在 Windows 上实机验收**：预置源能否访问（含公司网络 / 代理）、系统代理是否生效、动画流畅度与 CPU 占用、深浅主题下的狗狗观感
