# 喝水 / 起身提醒：狗狗卷起便签（方案，待审定）

> 需求：喝水提醒时间到，小狗把便签窗口卷起来，等确认后再展开。

---

## 一、效果（以喝水为例）

| 步骤 | 时长 | 画面 |
|---|---|---|
| 1. 预告 | 约 0.5 秒 | 狗狗从角落小跑到便签底部中间，抬头看你 |
| 2. 卷起 | 约 1.5 秒 | 狗狗跳起咬住便签纸的下边缘往下一拽（纸被拉长一点），松口后纸像卷帘一样「唰」地往上卷，卷成一根纸筒停在标题栏下方，轻轻弹一下 |
| 3. 提醒画面 | 等你点 | 纸卷上去后露出底下的「墙面」（比便签色稍深，带细纹）。狗狗坐在中间叼着水碗（起身提醒是伸懒腰），大字写「博士提醒你：喝口水吧」，小字写「今天第 3 杯」，下面两个按钮「喝好了」「10 分钟后」 |
| 4a. 点「喝好了」 | 约 2 秒 | 狗狗低头喝水 → 跳起抓住纸筒往下拉，纸跟着展开回原位 → 开心一下：「咕嘟咕嘟，舒服～」，杯数 +1 |
| 4b. 点「10 分钟后」 | 约 1.2 秒 | 狗狗叹口气，直接把纸拉下来：「那我 10 分钟后再来」 |

- 标题栏一直露在外面，照常可以拖动窗口、打开菜单。
- 卷起期间下面的事项列表点不到（被卷走了）。
- 起身提醒用同一套动作，只是狗狗不叼水碗，改成伸懒腰，文字换成「起来活动一下吧」。

## 二、实现方式

**推荐：在窗口里面做动画，窗口大小不变。**
- 事项列表从下往上收起，纸筒跟着往上走，动画只用位移和裁剪，交给显卡处理，比较流畅。
- 不改窗口尺寸，也不改数据库里保存的窗口位置和大小。

**不推荐：真把窗口缩成一行**（也就是复用双击标题栏折叠）。原因：
- WebView2 窗口逐帧改尺寸会闪黑边、会卡。
- 缩成一行后狗狗和按钮都没地方放。
- 会和保存的窗口高度、「钉在桌面」模式互相干扰。

## 三、规则与边界情况

| 情况 | 怎么处理 |
|---|---|
| 你正在打字或编辑（快速输入框开着、编辑框有焦点、最近 10 秒内按过键） | 先不卷。狗狗冒气泡「等你忙完～」，等你停手 10 秒后再卷 |
| 鼠标穿透开着 | 卷起期间临时关掉穿透，否则点不到按钮；透明度临时恢复 100%。点完按钮后都恢复原样。这套做法和事项强提醒一样 |
| 卷起期间来了事项强提醒 | 立刻展开（不放动画），先处理事项；这次喝水提醒按「10 分钟后」算 |
| 卷起期间按老板键 | 立刻展开并收起狗狗，按「10 分钟后」算 |
| 便签已经折叠成一行 | 不卷，只发系统通知（如果开了的话） |
| 免打扰、正经模式、不在上班时间、离开电脑超过 5 分钟 | 和现在一样，不提醒 |
| 窗口很矮（不到约 160 像素） | 用紧凑排版：狗狗缩小，文字和按钮挤成一行 |
| 一直不点按钮 | 一直卷着，等你确认（按你说的「确认后再展开」）。现在的「两分钟没理会就收起」只对气泡方式保留 |
| 系统开启了「减少动画」 | 不卷动，改为淡入淡出 |

**设置 → 摸鱼 → 狗狗 → 喝水 / 起身提醒** 新增：
- 「提醒方式」：卷起便签（默认）/ 只冒气泡（现在的样子）

## 四、测试与工作量

- **单元测试**：卷帘的状态切换（平常 → 卷起中 → 已卷起 → 展开中 → 平常），以及每种打断（强提醒、老板键、折叠）；「现在能不能卷」的判断（正在打字、窗口太矮、折叠、减少动画）。
- **端到端测试**（用虚拟时钟触发）：
  - 卷起后列表点不到；点「喝好了」后展开且杯数 +1。
  - 点「10 分钟后」，10 分钟后再次卷起。
  - 正在打字时推迟卷起。
  - 强提醒打断、老板键打断。
  - 鼠标穿透开着时按钮也能点。
  - 窗口很矮时用紧凑排版；「只冒气泡」选项和现在的行为一致。
- **需要你实机验收**：动画在你电脑上是否流畅，半透明时好不好看，打扰程度合不合适。
- **工作量**：中等。主要改前端（狗狗、便签、新加的卷帘层和样式），Go 端只加一个「临时需要点按钮」的开关，复用强提醒现有的暂停穿透逻辑。

## 五、需要你确认

1. **一直不点就一直卷着**（推荐，按你说的来）？还是超过若干分钟自动展开？
2. **起身提醒也用卷帘**，狗狗伸懒腰（推荐）？还是只有喝水用卷帘？
3. **设置里保留「只冒气泡」可选**，默认卷起（推荐）？
4. **鼠标穿透时临时关掉穿透**、透明度临时恢复 100%，以便点按钮（推荐）？
5. **正在打字时推迟到停手 10 秒后再卷**（推荐）？
